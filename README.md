# JobHub - Job Portal Website

A responsive frontend job portal portfolio project built with HTML5, CSS3 and JavaScript.

## Features
- Responsive design for mobile and desktop
- Job search by keyword and location
- Job type and experience filters
- Salary sorting
- Save job interaction
- Apply Now demo modal
- Login/Create Profile demo modal
- Popular job categories
- Clean portfolio-ready UI

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
- Responsive Web Design

## How to run
Open `index.html` in a browser.

## Project Structure
- `index.html` - page structure
- `style.css` - styling and responsive layout
- `script.js` - jobs data and interactive functionality

## Note
This is a frontend portfolio project. Real authentication, database, job posting and applications would require a backend.
